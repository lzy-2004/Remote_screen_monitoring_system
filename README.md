# 远程屏幕监控系统
## 使用方法
1.运行server.py与client,py(可以在同一台电脑或不同电脑上)  
2.在命令行输入服务器的ip地址  
3.在出现的界面中输入您喜爱的账号密码，并注册/登录（请先注册再登录），
已注册的账号以及密码会保存在一个txt文件中，密码以密文形式存储。  
4.点击stop client可停止进程  
5.点击Minimize To Tray可最小化到托盘  
6.托盘中右键图标可选择重新显示界面和退出  
7.在服务端可以更改图片发送频率  
## 注意事项
1.本项目来自北邮大型程序设计实践课程  
2.不要忘记那两个图片，否则会报错，这两个图片是托盘的照片
